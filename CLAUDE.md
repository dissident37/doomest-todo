# Самый тупой туду-лист

Личное приложение-список дел для телефона (Android в первую очередь). Открываешь вместо соцсетей, видишь свои дела, выбираешь одно.

- Требования MVP: `SPEC.md`
- Дизайн экранов (цвета, размеры, экраны): `DESIGN.md`
- План до готового MVP и порядок работы: `PLAN.md` — идти по нему, останавливаться только на контрольных точках.

## Статус

- Требования MVP — готовы.
- Дизайн 4 экранов — готов.
- Устройства: в MVP только Android-телефон (Samsung Galaxy S24). iPhone, планшет и ПК в браузере — позже (`SPEC.md`, раздел «Устройства»).
- Стек выбран: **React Native + Expo, TypeScript** (9 ноября 2026, обоснование в `SPEC.md`, раздел «Стек и архитектура»).
- Структура и библиотеки согласованы (10 ноября 2026): expo-sqlite без ORM, Gesture Handler + Reanimated, react-native-reorderable-list, fractional-indexing, expo-router.
- Скелет проекта на **Expo SDK 58** (11 ноября 2026 обновлён с 57: Expo Go в Google Play перешёл на SDK 58). Expo Go поддерживает только одну версию SDK — при его обновлении проект надо поднимать следом.
- Скелет запущен на S24 через Expo Go (11 ноября 2026). Если Expo Go зависает на 99% — нажать `r` в терминале или `npx expo start -c`.
- Прототип списка проверен на S24 (11 ноября 2026): свайп в обе стороны, «Отменить», перетаскивание, нажатие. Данные пока тестовые, в памяти.
- react-native-reorderable-list написана под Gesture Handler 2, у нас 3 — работает через старый API `Gesture.Pan()`, в типах нужно приведение (см. `src/app/index.tsx`).
- Вибрация (expo-haptics) добавлена, но на S24 в Expo Go не ощущается — не разобрано, отложено.
- Хранение в SQLite (11 ноября 2026): `src/data/` — база, миграции по `PRAGMA user_version`, `TasksProvider` для экранов. Тестовые дела засеваются только в `__DEV__`, один раз при создании базы. Проверено на S24.
- Экран карточки дела и «+» через карточку (11 ноября 2026). Новое дело создаётся в базе с первой буквой заголовка; пустой заголовок не сохраняется. Проверено на S24; при открытой клавиатуре нижние блоки карточки прячутся.
- Голосовой ввод — клавиатурой Samsung; язык диктовки настраивается в клавиатуре, не в приложении.
- Дальше — по `PLAN.md`.

## Структура кода

- `src/app/` — экраны (Expo Router), `src/domain/` — чистая логика без React Native, `src/data/` — SQLite, `src/ui/` — компоненты, `src/theme/` — токены из `DESIGN.md`.
- Правила работы с Expo (команды, версии, документация) — `AGENTS.md`. Библиотеки ставить только через `npx expo install`.

## Окружение разработки

- Ноутбук ASUS VivoBook на Windows 11: Ryzen 5 3500U, 8 ГБ RAM (системе доступно около 6). Mac нет.
- Android Studio и эмулятор не ставим — ноутбук не тянет. Запуск — на S24 через Expo Go, сборка APK — в облаке EAS Build.
- Node.js 24. Git: коммиты от аккаунта GitHub `dissident37@gmail.com` (задано в настройках репозитория), репозиторий на GitHub — публичный: https://github.com/dissident37/doomest-todo

## Как со мной работать

- Общаемся по-русски, коротко и по делу. Азы не объяснять.
- Версии, команды и возможности инструментов — проверять по актуальным источникам. Явно помечать, что проверено, а что по памяти.
- MVP узкий. Функции из раздела «Вне MVP» не добавлять без моего запроса.
- Перед крупным решением (стек, структура проекта, библиотеки) — сначала предложить варианты, потом делать.
