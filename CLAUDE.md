# Самый тупой туду-лист

Личное приложение-список дел для телефона (Android в первую очередь). Открываешь вместо соцсетей, видишь свои дела, выбираешь одно.

- Требования MVP: `SPEC.md`
- Дизайн экранов (цвета, размеры, экраны): `DESIGN.md`

## Статус

- Требования MVP — готовы.
- Дизайн 4 экранов — готов.
- Устройства: в MVP только Android-телефон (Samsung Galaxy S24). iPhone, планшет и ПК в браузере — позже (`SPEC.md`, раздел «Устройства»).
- Стек выбран: **React Native + Expo, TypeScript** (9 ноября 2026, обоснование в `SPEC.md`, раздел «Стек и архитектура»).
- Структура и библиотеки согласованы (10 ноября 2026): expo-sqlite без ORM, Gesture Handler + Reanimated, react-native-reorderable-list, fractional-indexing, expo-router.
- Скелет проекта создан на **Expo SDK 57**, не 58: Expo Go в Google Play пока поддерживает только SDK 57.
- Следующий шаг: проверить скелет на S24 через Expo Go, затем прототип списка со свайпом и перетаскиванием.

## Структура кода

- `src/app/` — экраны (Expo Router), `src/domain/` — чистая логика без React Native, `src/data/` — SQLite, `src/ui/` — компоненты, `src/theme/` — токены из `DESIGN.md`.
- Правила работы с Expo (команды, версии, документация) — `AGENTS.md`. Библиотеки ставить только через `npx expo install`.

## Окружение разработки

- Ноутбук ASUS VivoBook на Windows 11: Ryzen 5 3500U, 8 ГБ RAM (системе доступно около 6). Mac нет.
- Android Studio и эмулятор не ставим — ноутбук не тянет. Запуск — на S24 через Expo Go, сборка APK — в облаке EAS Build.
- Node.js 24. Git: коммиты от аккаунта GitHub `dissident37@gmail.com` (задано в настройках репозитория), репозиторий на GitHub — публичный: https://github.com/dissident37/doomest-todo

- Общаемся по-русски, коротко и по делу. Азы не объяснять.
